# MyBestPrice: Landing Page

Pre-launch website for **[mybestprice.lk](https://mybestprice.lk)**, Sri Lanka's negotiation-first marketplace for property, vehicles and electronics.

Buyers make offers, sellers choose, and either side can **Meet in the Middle**. Contact details are shared only after both agree on a price.

## Contents

| File | Purpose |
|---|---|
| `index.html` | Landing page |
| `privacy.html` | Privacy notice |
| `assets/` | Logo and icon (SVG, light and dark versions) |
| `favicon.*`, `*-icon*.png`, `site.webmanifest` | Browser and phone icons, web app manifest |
| `og-image.png` | Link preview image (1200×630) |
| `CNAME` | Custom domain for GitHub Pages |
| `.nojekyll` | Serve files as-is on GitHub Pages |

A static site: plain HTML and CSS, no build step and no dependencies.

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```
